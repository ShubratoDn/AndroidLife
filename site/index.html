How it works

Three steps, about two minutes.

Install the APK

Download PhoneDeck from the GitHub releases page and open it on your Android phone.

Pair once

Tap Make visible in the app and add the phone in your PC's Bluetooth settings. It reconnects by itself afterwards.

Play, type or transfer

Pick a tool. In ETS2 select TruckPad as the controller and bind the controls.

FAQ

Do I need to install anything on my PC?

No. The steering wheel, keyboard and mouse use Bluetooth like any wireless gamepad or keyboard. File Transfer and Live View open in a normal web browser.

Can I use my phone as a steering wheel for Euro Truck Simulator 2?

Yes. PhoneDeck appears as a standard Bluetooth game controller with a steering axis, gas and brake pedals and buttons for every cockpit function. Steer with the on-screen wheel or by turning the phone.

Does it work with American Truck Simulator and other games?

Any game that supports game controllers can use it. The layout is designed around Euro Truck Simulator 2, which shares its controls with American Truck Simulator.

Do I need root?

No. Only the optional Charging Animation tool needs a rooted phone with LSPosed.

Which phones are supported?

Android 9 or newer. A few manufacturer systems turn off the Bluetooth HID Device profile; on those the PC tools can't connect, but every phone tool still works.
